# 介面模板截圖

程式靠這些小截圖在畫面上找到 LINE 的按鈕和輸入框。請用 Windows 的「剪取工具」（Win + Shift + S）截圖，存成 PNG 放在這個資料夾。

| 檔名 | 要截什麼 | 注意事項 |
|---|---|---|
| `search_box.png` | LINE 主視窗左上方「搜尋好友/聊天」的輸入框（含放大鏡圖示） | 在框裡沒有文字、沒有點進去的狀態下截圖 |
| `input_box.png` | 聊天室下方「輸入訊息」那一塊，最好包含提示文字 | 隨便打開一個聊天室來截，輸入框要是空的 |

小技巧：

- 截圖範圍不要太大，只要包含能辨識的特徵就好（大約 150×40 px）。
- 截圖時的 Windows 螢幕縮放比例、LINE 視窗大小、深色或淺色主題，都要和平常執行程式時一樣。
- 換螢幕、改縮放比例，或 LINE 改版之後，比對可能會失敗。程式會把失敗當下的畫面存到 `data/debug/`，到時候重新截圖就好。
- 比對太嚴格的話，可以調低 `config.yaml` 裡的 `ui.match_threshold`（例如 0.7）。
